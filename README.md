# Daily Expense Tracker

**An AWS-Based Cloud-Hosted Expense Management Application**

## Project Overview
Daily Expense Tracker is a web-based application developed to manage daily expenses and monitor monthly spending.

## Features
- Add daily expenses with amount, category and date.
- Search and delete expense records.
- Calculate total and monthly spending.
- View category-wise spending charts.
- Set a monthly budget and track remaining balance.
- Export expense records as CSV.

## Technologies Used
- HTML
- CSS
- JavaScript
- Amazon Web Services (AWS S3)
- Browser LocalStorage

## AWS Deployment
The application is deployed using Amazon S3 Static Website Hosting.

## Data Storage
Expense records and budget information are stored locally in the browser using LocalStorage. The application does not currently use a cloud database.
